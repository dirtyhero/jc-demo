## 1. 背景

私たちのまちでは、季節ごとにさまざまな地域行事がひらかれています。しかし、行事に来る人は毎年ほぼ同じ顔ぶれになっており、新しい参加者が増えていません。

なかでも、子育て世代の姿はあまり見られません。子育て世代は、仕事と育児に追われて地域の情報に触れる機会が少なく、行事があることを知らないままのことも多いと考えられます。また、知っていても「子どもを連れて行ってよいのか」「行っても知り合いがいない」と感じ、足が向きにくい状況があります。

このまま参加者が固定化すると、行事を支える担い手が高齢化し、地域のつながりも細くなっていきます。次の世代を担う子育て世代と、その子どもたちが地域と出会うきっかけをつくることが必要です。

> 【要確認】参加者が固定化していることを示すデータ（過去の行事の参加者数、年代構成、リピーターの割合など）があれば、ここに追記してください。

## 2. 目的

- 市内の子育て世代が、親子で気軽に参加できる地域行事をつくる
- 行事をきっかけに、子育て世代と地域の人たちとのつながりを生む
- 行事の参加者の顔ぶれを広げ、地域行事の担い手となる次の世代を育てる

## 3. 目指す姿

親子で参加できる行事が年2回ひらかれ、毎回、初めて地域行事に来た親子が参加している。参加した親子が次の行事にも戻ってきたり、知り合いを誘ったりすることで、地域行事の参加者の輪が年々広がっている。

## 4. 事業内容

### 4-1. 企画の考え方

- **親子で一緒に楽しめる**：子どもを預ける場ではなく、親子が一緒に体験できる内容にする
- **初めてでも入りやすい**：予約なし・短時間でも参加できるようにし、受付や案内を丁寧にする
- **地域の人と出会える**：地域の団体や商店、町内会の人が出展・運営に加わり、自然に交流が生まれる場にする
- **子育て世代に届く告知**：保育園・幼稚園・小学校、子育て支援センター、SNSなど、子育て世代がふだん触れる経路で知らせる

| 項目 | 内容 |
| --- | --- |
| 日時 | 2027年【要確認】月〇日（土・日） 10:00〜15:00 |
| 会場 | 【要確認】市内の公園・広場など（屋外。雨天時の代替会場も確保する） |
| 内容（案） | 親子で参加する外遊び・運動あそび、地域の団体による体験ブース（工作、昔あそびなど）、キッチンカー・地元商店の出店 |

### 4-3. 第2回（秋）

| 項目 | 内容 |
| --- | --- |
| 日時 | 2027年【要確認】月〇日（土・日） 10:00〜15:00 |

| 内容（案） | 第1回のアンケートを踏まえて内容を見直す。例：親子でつくる収穫祭・ものづくり体験、地域の人と一緒にまわるスタンプラリー |

### 4-4. 協力を依頼する団体（案）

- 市（子育て支援担当課）、市教育委員会
- 保育園・幼稚園・小学校、PTA
- 町内会・自治会、地域の子育てサークル
- 地元の商店・企業

> 【要確認】後援・協力の依頼先は、担当委員会で調整のうえ確定してください。

## 5. 期待される効果

- 地域行事に、これまで来ていなかった子育て世代の親子が参加する
- 親子と地域の人たちが顔を合わせ、地域のつながりが生まれる
- 参加した親子が、ほかの地域行事にも関心を持つきっかけになる
- 協力団体とのつながりができ、次年度以降も続けられる体制の土台になる

## 6. 検証方法

各回で次の項目を記録し、事業報告で目標と比べて検証します。

| 指標 | 測り方 | 目標 |
| --- | --- | --- |
| 参加組数 | 受付での集計 | 各回 【要確認】〇〇組 |
| 初参加の割合 | 受付またはアンケートで「地域行事に初めて参加した」と答えた割合 | 〇割以上 |
| 満足度 | 参加者アンケート | 「また参加したい」〇割以上 |
| リピート率 | 第2回で「第1回にも参加した」と答えた割合 | 〇割以上 |

第1回の結果は、第2回の企画と告知の見直しに使います。

## 9. リスクと対策

| リスク | 対策 |
| --- | --- |
| 雨天・荒天 | 屋内の代替会場を確保する。中止の判断基準と連絡方法を事前に決める |
| 子どもの事故・けが | イベント保険に加入する。救護スペースを設け、見守りのスタッフを配置する |
| 参加者が集まらない | 園・学校経由の告知を早めに行う。第1回の結果をもとに第2回の告知を見直す |
| 参加者が多すぎる | 体験ブースは整理券制にする。会場の導線を事前に確認する |
